# Yunus Emre Yılmaz — Language Room

A personal portfolio built as an interactive study/work room rather than a conventional website.

The room currently contains interactive sections for:

- English teaching
- Translation and language work
- Squad Index
- Reflect & Shoot
- YouTube
- X / Twitter
- Library / resources
- About

## Stack

- Next.js
- TypeScript
- Motion for React
- CSS-based 2.5D scene

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current status

This is the first working visual prototype. The next design pass will replace or enhance the CSS-made room objects with a stronger illustrated asset system while preserving the same interaction model.
