# Third-party assets

## Kenney Furniture Kit

Source: https://kenney.nl/assets/furniture-kit
License: CC0 1.0

Language Room v2 currently loads a small curated set of GLB models from the public Kenney asset mirror at `ETdoFresh/kenney.nl`:

- `chairDesk.glb`
- `bookcaseOpen.glb`
- `books.glb`
- `computerKeyboard.glb`
- `computerMouse.glb`

The monitor, desk, lamp, notebook, camera, microphone, phone, room shell and wall elements are authored in the application with Three.js geometry so their proportions can be controlled precisely for the interaction design.

CC0 does not require attribution, but this file records provenance intentionally. Before a production release, preferred assets can be vendored into `/public/models` and optimized with glTF tooling instead of relying on remote raw URLs.
